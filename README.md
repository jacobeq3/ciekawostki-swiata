# Ciekawostki Świata

Strona statyczna przygotowana pod GitHub Pages.

## Co poprawiono
- lepsze meta dane SEO i canonical URL;
- Open Graph i podstawowe dane strukturalne Schema.org;
- robots.txt i sitemap.xml;
- więcej ciekawostek i lepsze pokrycie kategorii;
- wyszukiwanie działa na bieżąco podczas wpisywania;
- poprawiona sekcja „O stronie” i linki nawigacyjne;
- responsywny układ reklam dla telefonu i komputera;
- uporządkowane miejsca reklamowe bez zachęcania użytkownika do klikania reklam.
